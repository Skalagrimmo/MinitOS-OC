## Regenerating K1

Check out the tag in a separate worktree or clone, then run its tools:

```sh
git switch --detach k1-baseline
python tools/acceptance.py --evidence
```

Do not run this in a K2 working tree: it would replace the current K2 artifacts.
K2's acceptance script does not write into `docs/evidence/k1/`.

## Scope

The K1 evidence proves the K1 boot, PL011 banner and QEMU execution path only.
It does not include active exception handling, per-mode stacks, the low vector
table or fault diagnostics; those are K2 results recorded in
`../../K2_ACCEPTANCE.md`.
